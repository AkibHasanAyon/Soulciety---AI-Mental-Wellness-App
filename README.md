**Soulciety** is an AI-powered spiritual growth and self-transformation mobile application backend designed to serve as a personal consciousness mentor.

The platform integrates conversational AI with continuous semantic memory, reflective journaling with poetic AI insights, community engagement feeds, daily mood tracking, and a curated spiritual media library.

## ✨ Key Feature Modules

### 1. 🤖 AI Mentor & 3-Tier Long-Term Memory (`chat/`, `memory/`)
* **Asynchronous AI Chat**: API immediately acknowledges inbound messages (HTTP 202) while Celery handles background reflection via `gemini-3-flash-preview`.
* **Empathetic Pacing & Safety**: Adheres to strict emotional validation protocols before coaching, along with crisis helpline escalation.
* **Tier 1 — Structured Fact Extraction**: Automatically categorizes facts (identity, career, family, spiritual beliefs, patterns) every 10 messages.
* **Tier 2 — Conversation Summaries**: Generates narrative takeaways and tracks dominant emotional states.
* **Tier 3 — Semantic Vector Memory (ChromaDB)**: Injects contextually relevant past memories into chat prompts using `text-embedding-004` cosine similarity.

### 2. 📝 Reflective Journaling (`journal/`)
* Users log private entries with mood indicators (Happy, Fear, Sad, Angry, Sick).
* **AI Spiritual Insights**: Celery task generates 3-sentence poetic reflections and pushes a notification teaser to the user.
* Archive and unarchive management.

### 3. 👥 Community Social Network (`community/`)
* Social feed with tabs: *All*, *Following*, and *My Posts*.
* Image uploads hosted on Cloudinary with automatic file lifecycle cleanup.
* Atomic like counters, thread comments, user following, and report handling.
* **9:00 AM Daily Prompt (Celery Beat)**: Automated daily reflective prompts generated by `gemini-2.5-flash` to spark community conversation.

### 4. 🧘 Curated Spiritual Media (`spiritual/`)
* Categorized video streaming library with thumbnail integration and view tracking.
* Direct Cloudinary video streaming with automatic duration extraction.
* User bookmarks and personalized recommended videos.

### 5. ☀️ Daily Experience & Home Aggregator (`app_home/`)
* **Mood-Aware Daily Quotes**: Personalized AI quote generated dynamically based on the user's latest mood check-in (cached daily).
* **Daily Moves**: Admin-curated mindfulness practices and featured products.
* Single aggregated API endpoint `/api/home/` to minimize mobile network roundtrips.

| Module | Route Prefix | Key Endpoints | Purpose |

## 🛠️ Technology Stack

* **Backend**: Django 5.2.9, Django REST Framework
* **AI & NLP**: Google GenAI SDK (`gemini-3-flash-preview`, `gemini-2.5-flash`, `text-embedding-004`)
* **Vector Store**: ChromaDB
* **Task Queue**: Celery with Redis broker and Celery Beat
* **Media Management**: Cloudinary Storage
* **Push Notifications**: Firebase Admin SDK (FCM)
* **Auth**: SimpleJWT, Google/Apple OAuth

## ⚙️ Installation & Deployment

### Run with Docker Compose (Recommended)

1. **Enter directory**:
   ```bash
   cd Soulciety---AI-Mental-Wellness-App
   ```

2. **Configure environment**:
   ```bash
   cp .env.example .env
   # Set GEMINI_API_KEY, CLOUDINARY_URL, and FIREBASE credentials
   ```

3. **Build and launch services**:
   ```bash
   docker-compose up --build -d
   ```
   *Spins up: `web` (Gunicorn), `worker` (Celery), `beat` (Celery Beat), and `redis`.*

4. **Run migrations**:
   ```bash
   docker-compose exec web python manage.py migrate
   ```

### Local Development Setup

```bash
python -m venv venv
source venv/bin/activate  # On Windows: .\venv\Scripts\activate
pip install -r requirements.txt

# Start Redis locally (port 6379)
python manage.py migrate
python manage.py runserver
```
